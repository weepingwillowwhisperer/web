# Willow — GitHub Pages deployment

Live site: https://weepingwillowwhisperer.github.io/web/

## How to build/publish
This is a static site (HTML/CSS only). GitHub Pages builds & publishes automatically from `main` → `/` (root).

### Quick dev preview
- Clone repository: `git clone https://github.com/weepingwillowwhisperer/web.git`
- Open `index.html` in a browser

### Deploy changes
- Commit changes to `main`
- Push to GitHub
- GitHub Pages workflow will run (`pages build and deployment`) and update the live site.
